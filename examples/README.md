# StockX Scraper API – code examples

Examples for every StockX endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/product.sh`](curl/product.sh) | `bash product.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| cURL (Bash) | [`curl/trends.sh`](curl/trends.sh) | `bash trends.sh` |
